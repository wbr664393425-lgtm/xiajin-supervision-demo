# 阶段 B 独立设计预览

仅用于三个设计方向的比较，不连接原平台状态、数据库或真实模型，不生成正式核查任务。页面轻交互保存在当前内存中，刷新恢复固定虚构案例。

从项目根目录启动：

```sh
python3 -m http.server 5174 --bind 127.0.0.1 --directory design/stage-b
```

- 三案对照：http://127.0.0.1:5174/
- 六张完整视觉稿：http://127.0.0.1:5174/boards.html
- 各方案目录：`a/`、`b/`、`c/`。入口是默认页；加 `?view=work` 直达核心研判布局。
- `case.js` 为统一虚构案例，原平台数据未改动。
- `entry-concept.png` / `concept.png` 是内置ImageGen视觉探索，提示词与v2修订随目录保存；它们不是浏览器截图。
- `index.html` / `app.js` / `style.css` 是清晰中文与轻交互的原生展示稿，不承诺与生成图逐像素相同。

修订：用户否定暖色和古风后，当前稿统一纯白、中性灰、蓝色操作与现代sans；三案靠任务组织、阅读/编辑方式和证据检视区分。

检查：三案JS语法及CSS解析通过。本地预览浏览器访问仍被已保存站点权限阻止；用户文字授权尚未改变底层设置。未绕过该限制。1440×900与1920×1080的实际页面截图和点击走查尚未完成，不能称为视觉验收通过。

真实政务网站参考见上一级 `02-government-references.md`，五维比较与评审问题见 `02-directions.md`。阶段 B 三案和组合稿保留作评审记录。用户已认可 B 入口 + A 审阅，阶段 C 原型位于 `prototype/`，地址：http://127.0.0.1:5174/prototype/ 。详见该目录 README。正式业务实现阶段 D 尚未开始；当前页面实际验收由用户自行进行。
