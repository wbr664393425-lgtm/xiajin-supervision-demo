# 夏津县纪检监察智能监督与执纪办案一体化平台 · 演示版（v2）

面向客户汇报的桌面 Web 演示。覆盖功能清单的八大模块：信访举报与线索研判、大数据穿透监督、智能巡察辅助、案件审理与案卷、廉政档案与画像、廉洁教育与舆情、AI 智能体、安全与管控。每个功能都形成“材料/数据 → 规则引擎出疑点 → 人工确认 → 核查任务/文书 → 审计留痕”的可操作闭环。

**全站标有“样例/演示”水印。14 个乡镇统一使用乡镇A至乡镇N，地图采用演示分区。村居、人物、单位、合同、金额及举报材料均为虚构样本。AI 输出仅为疑点、初稿与参考，定性、量纪、审批与处置权由纪检干部行使。**

2026-11-06 起为 v2：在原仓库从零重写 `src`，采用党建红视觉方案（主色 `#C91519`、浅红 `#FDE9E9`、暖米 `#FFF6E6`、文字 `#333333`），视觉规范见 [design.md](design.md)。旧版完整代码保存在 `archive/v1/`，仅供对照，不参与构建。

## 启动

需要 Node.js 20.19+ 或 22.12+。在本目录执行：

```bash
npm install
npm run dev
```

默认仅绑定本机，浏览器打开 [http://127.0.0.1:5186/#/](http://127.0.0.1:5186/#/)。端口固定 5186，被占用时用 `npm run dev -- --port 5187`。

在登录页手动输入既有账号和密码。「记住账号」仅保存账号名。首次直达业务链接时，登录成功后会回到原页。移动服务器使用服务端会话，退出后该会话立即失效；本地静态演示保留浏览器模拟登录。

```bash
npm run test
npm run build
npm run preview -- --port 4173
```

构建产物在 `dist/`，脚本、样式、图标全部本地打包，可断网演示；请用静态 HTTP 服务托管，不要用 `file://` 直接打开。

移动服务器演示入口为 [br20.xiaoyuqi.top](https://br20.xiaoyuqi.top/)，默认端口无法访问时可使用 [8443 备用 HTTPS 入口](https://br20.xiaoyuqi.top:8443/)。两个入口的浏览器演示记录按端口分别保存；端口状态、发布、巡检与回滚步骤见[运维手册](docs/运维手册.md)。

## DeepSeek 大模型接入（智能助手）

纪检助手页、顶栏智能助手侧边面板与全景研判已接入 DeepSeek（OpenAI 兼容网关，模型 `deepseek-v4-flash`），流式实时返回。界面统一称“纪检大模型 / 离线引擎”，不展示模型名；可在助手页顶部切换「纪检大模型 / 离线引擎」，并可开启「深度思考」。左侧栏底部“智能引擎”显示在线状态，便于演示前确认网络。

- 配置：复制 `.env.example` 为 `.env.local` 填写 `LLM_BASE_URL`、`LLM_HOST_HEADER`、`LLM_MODEL`、`LLM_API_KEY`。`.env.local` 已被 `.gitignore` 忽略。
- 密钥安全：浏览器向同源 `/api/llm/chat/completions` 发起请求。开发和预览环境由 Vite 转发，移动服务器由本站 API 验证会话并附加密钥。修改本机配置后重启 Vite，修改服务器模型配置后重启本站 API。
- 角色与边界：系统提示词见 `src/engines/prompts.ts`，限定为“纪检监察智能助手”，禁止编造事实与条款编号、禁止定性量纪处置，输出固定分段格式并以“使用提醒”收尾；生成后再做边界自检，发现定性类表述会追加提醒。法规问答会先检索本地知识库，把条目作为参考资料并要求标注 [n]。
- 回退：网关不可用或未配置时静默改用离线引擎（本地规则与知识库），步骤显示“离线引擎生成”，不弹错误提示；原因写入浏览器控制台。
- 注意：启用后助手中的输入内容会发送到外部模型网关，只能使用虚构演示材料，不得输入真实敏感或涉密信息。`dist/` 静态托管时没有代理，助手会自动使用本地规则。

## 数据、持久化与边界

- 演示进度保存在浏览器 `localStorage`，键前缀 `xiajin-v2:`；右上角角色菜单 →「重置数据」恢复初始样例。不同端口、不同设备进度相互独立。
- 业务日期固定为汇报当天 `2026-11-07`（`src/stores/persist.ts` 的 `today`），超期、到期、问候栏日期与文书落款均按此计算；改期时修改此处并重核演示脚本数字。
- 风险一张图：县界为阿里云 DataV.GeoAtlas 行政区划边界（adcode 371427），乡镇点位按演示版面独立布置，再做 Voronoi 划分。数据与来源说明在 `src/mock/xiajin-map.ts`；样例乡镇 id 沿用旧编号，名称映射见 `src/mock/geo.ts`。
- 界面文案不再逐处标注“演示 / 模拟 / 虚构”，统一由页脚一行与 安全与管控 › 数据对接 如实说明数据与对接状态。
- 规则引擎为本地确定性规则（`src/engines/`），每个引擎都有单元测试。除智能助手可选接入 DeepSeek 外，没有接入真实 OCR、语音转写、政务共享数据或业务系统；扫描件、照片、录音使用内置样例并标注“模拟”。
- 知识库条目是演示摘要，不是权威原文，不含真实条款编号；文书校核不会代填条款编号。
- 页面内角色切换用于演示不同业务视图。公网入口的账号校验和模型访问控制由服务器执行。

## 项目结构

```text
src/
  app/        外壳（品牌条、模块导航、功能栏、全局检索、智能助手侧边面板、提示）、路由与权限、URL 状态组合式函数
  design/     tokens.css / base.css，ui/ 通用组件（按钮、卡片、标签、风险徽标、抽屉、弹窗、时间轴等）
  charts/     自研 SVG 图表：折线、环形、条形、乡镇蜂窝热力、关系图谱
  engines/    规则引擎与单元测试：信访解析/判重/分级/图谱/时限、穿透监督、巡察、审理案卷、档案舆情、AI 助手
  mock/       分域虚构数据
  stores/     按域拆分的 Pinia 仓库与持久化
  modules/    八大模块的功能页面
archive/v1/   旧版代码（只读对照）
docs/         演示脚本、功能验收清单、数据说明、截图
```

技术栈：Vue 3、TypeScript、Vite、Vue Router、Pinia、Lucide 图标；未新增依赖。
