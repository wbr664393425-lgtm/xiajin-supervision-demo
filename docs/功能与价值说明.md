# 夏津县纪检监察智能监督与执纪办案一体化平台 · 功能与价值说明

供汇报讲解使用。操作路线见 [演示脚本](演示脚本.md)。

## 一句话定位

把信访、监督、巡察、审理、档案、教育六项业务放到一个平台上，由智能引擎完成“读材料、比数据、找疑点、写初稿”，纪检干部负责确认、定性和处置，全过程留痕可查。

每个功能都按同一条线运转：**材料/数据 → 智能发现疑点 → 人工确认 → 核查任务/文书 → 审计留痕**。

## 各模块功能与价值

| 功能 | 做什么 | 价值 |
| --- | --- | --- |

## 整体价值（收尾可讲）

1. **提效**：登记、阅卷、比对、起草这些耗时的基础工作交给系统，干部把精力放在核查和判断上。
2. **提质**：疑点有规则、有证据、有原文出处；文书有校核，整改有比对。
3. **贯通**：信访、监督、巡察、审理的数据打通，一个人、一份合同的情况可以跨模块串起来看。
4. **可控**：智能只提疑点、出初稿、给参考；定性、量纪、审批、处置由纪检干部决定，每一步有人工确认和审计留痕。
5. **安全**：正式部署时大模型、知识库和业务数据全部运行在政务内网。

## 讲解时注意

- 页面中的乡镇、村居、人员、单位、金额和材料均为样例。
